# Cheat sheets & Technical Documantation

This repository serves as my personal knowledge base and documentation hub.
It contains quick-reference guides, syntax sheets, and CLI references for various operating systems, network services, and administration tools.

The goal of this repository is to maintain clean, practical, and fast-to-navigate documentation for daily systems administration and troubleshooting.

---

### Repository Structure

* **`linux/`** — Command references, systemd, LVM, SSH, and Bash tips.
* **`windows/`** — PowerShell cmdlets, Active Directory commands, and Windows Server administration.
* **`cli-tools/`** — Handy guides for cross-platform utilities like Git, tmux, Vim, and Docker.
* **`networking/`** — Network configuration, troubleshooting, subnetting, firewall rules, and service configs.
